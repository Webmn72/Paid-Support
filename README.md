# Paid — Support

This repository hosts the public support site for **Paid**, an iOS app for pay-period budgeting, bill scheduling, and forward-looking cash flow planning.

**Live site:** https://webmn72.github.io/Paid-Support/

## What's here

- `docs/index.html` — Support home page (contact, FAQ, troubleshooting)
- `docs/privacy.html` — Privacy policy

The site is served via **GitHub Pages** from the `docs/` folder on the `main` branch.

## Getting help

- Email: **paidappsupport@icloud.com**
- For bug reports or feature requests, please open an [Issue](../../issues).
